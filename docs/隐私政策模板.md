# 拾词输入法 隐私政策

**生效日期**：【2026-XX-XX】

感谢您使用拾词输入法（以下简称"本软件"）。本软件是一款**完全在设备本地运行**的输入法，
核心设计原则是"认识你，但不需要服务器认识你"。本政策说明我们如何处理您的信息。

## 一、我们收集的信息

**我们不会收集、上传、传输您的任何输入内容或个人数据。**

本软件在默认配置下：

- 不申请网络访问（`INTERNET`）权限；
- 不收集您输入的文字、候选选择、拼音串；
- 不收集设备标识符、位置、通讯录；
- 不含任何第三方统计、广告或 SDK；
- 不与任何服务器通信。

## 二、数据的本地存储

为保障输入体验与学习功能，本软件仅在**您的设备本地**存储以下数据，绝不离开设备：

- 输入法运行时缓存（候选、词频）；
- 学习功能产生的生词本、复习记录（SQLite，本机）；
- 您主动导入的词表文件。

上述数据仅保存在应用私有目录，您可通过系统"清除应用数据"或卸载彻底删除。

## 三、权限说明

| 权限 | 用途 | 是否必须 |
|---|---|---|
| 输入法服务（绑定输入法） | 提供键盘输入能力 | 是（输入法必需） |
| 存储（读取导入词表） | 导入本地 CSV 词表 | 仅导入时 |
| 网络 | **默认不申请** | 否 |

本软件不请求短信、通讯录、定位、麦克风、摄像头等敏感权限。

## 四、未成年人保护

本软件不含面向未成年人的定向内容，亦不主动收集未成年人信息。建议未成年人在监护人指导下使用。

## 五、您的权利

由于本软件不收集任何个人数据，您无需注销账号。
如需删除全部本地数据：系统设置 → 应用 → 拾词输入法 → 清除数据 / 卸载。

## 六、政策更新

如本软件未来引入联网功能（如可选云翻译），我们将在此页面更新并重新征求您的同意。
重大变更将通过应用内提示告知。
