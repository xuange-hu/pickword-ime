# 软件著作权申请材料清单与模板（个人 / 自然人申请）

> 适用：以个人身份为「拾词输入法」申请软件著作权。
> 费用：普通登记**官费 0 元**（2026 年自然人免费政策；代理另计）。
> 周期：形式审查约 **30–40 个工作日（1–2 个月）**。
> 原则：源码页是"提交时点的快照"，**无需等整体完成**，P1 MVP 完成后即可提交。

---

## 一、材料清单（逐条打勾）

- [ ] **中国版权保护中心账号实名认证**（1–3 个工作日）
      - 地址：https://register.ccopyright.com.cn/
      - 选"个人/自然人"，上传身份证，认证成功后才可申报。
- [ ] **源代码（前 30 页 + 后 30 页，共 60 页）**
      - 每页 ≥ 50 行；不足 60 页（约 3000 行）则全部提交。
      - 页眉标注：**软件全称 + 版本号 + 页码**；最后一页应为程序结束部分。
      - 关键算法部分保留，不得使用截图或反编译结果。
      - 见下方"源码页抽取方法"（fork Trime 后代码量远超 60 页，直接抽前/后各 30 页）。
- [ ] **软件说明书 / 用户手册（任选一种）**
      - 图文结合，≥ 10 页，体现核心功能逻辑与独创性（避免纯界面截图）。
      - 页眉同样标注软件名 + 版本号 + 页码。
      - 大纲模板见第四节。
- [ ] **申请人身份证明**
      - 自然人：身份证正反面复印件（或扫描件）。
- [ ] **《非职务开发证明》**（模板见第三节）
      - 证明软件为独立开发、非任职单位职务作品。学生/无雇主者天然符合。
- [ ] **在线填写《计算机软件著作权登记申请表》（R11）**
      - 软件名称、版本号、开发完成日期、开发方式（独立开发）、功能说明（500–1300 字）。
      - 2026 年新版申请表，旧版不予受理。

---

## 二、提交流程

1. 注册并完成实名认证（现在就能做）。
2. 准备源码页 + 用户手册（边开发边整理，P1 完成后定稿）。
3. 在线填 R11 申请表，上传材料扫描件。
4. 提交生成受理号，在线缴官费（普通 0 元）。
5. 形式审查，不符则 30 个工作日内补正。
6. 审查通过公告 3 天，颁发《计算机软件著作权登记证书》。

## 五、源码页抽取方法（Python 示例）

将仓库源码合并抽取前 30 页 + 后 30 页（每页 50 行，带页眉）。
下面脚本为思路示意，实际需按仓库语言过滤、跳过空行/资源文件：

```python
# extract_copyright_source.py（示意）
import os, glob

LINES_PER_PAGE = 50
PAGES = 30
src_files = []
for ext in ("*.kt", "*.java", "*.js", "*.ts"):
    src_files += glob.glob(f"app/**/{ext}", recursive=True)

lines = []
for f in src_files:
    with open(f, encoding="utf-8", errors="ignore") as fh:
        for ln in fh:
            lines.append(ln.rstrip("\n"))

total = len(lines)
per_page = LINES_PER_PAGE
header = "拾词输入法 V1.0"

def dump(page_lines, page_no, out):
    out.write(f"{header}    第 {page_no} 页\n")
    for i, ln in enumerate(page_lines[:per_page], 1):
        out.write(f"{i:>3}  {ln}\n")

front = lines[: PAGES * per_page]
back = lines[-PAGES * per_page:] if total > 2 * PAGES * per_page else lines[total - PAGES*per_page:]
# 注意：不足 60 页时按"全部提交"处理（去掉 back，仅输出全部）
with open("copyright_source.txt", "w", encoding="utf-8") as out:
    # 全部不足 60 页：直接全部；否则前30+后30
    if total <= 2 * PAGES * per_page:
        dump(lines, 1, out)  # 简化：实际应分页连续编号
    else:
        for p, start in enumerate(range(0, len(front), per_page), 1):
            dump(front[start:start+per_page], p, out)
        for p, start in enumerate(range(0, len(back), per_page), PAGES+1):
            dump(back[start:start+per_page], p, out)
```

> 实际提交前请人工核对：每页行数、页眉一致、首尾页完整、无乱码。

## 六、注意事项

- **名称一致性**：软著登记名称 = App 名 = 桌面显示名，**一字不差**。
- 版本号填当前真实版本（如 V1.0）；后续大改可做"变更登记"。
- 审查为形式审查，不编译、不运行、不比对上架 App 代码；商店仅核验名称与证书有效。
- fork 的 Trime（GPL-3.0）代码可一并提交，你登记的是"衍生作品 V1.0"，与 GPL 公开源码要求不冲突。
