# 商店上架指南（个人开发者路径）

> 目标：把 P1 的内测包送到酷安，P4 正式上架酷安 + OPPO / vivo，开源侧同步 F-Droid。
> **政策会变**：各平台的开发者协议与审核规则每年调整，提交前请以对应开放平台的**最新官方文档**为准；
> 本文件给出的是路径、材料清单与红线，具体表单项以页面提示为准。

## 一、渠道选择（按优先级）

| 渠道 | 主体要求 | 软著 | 隐私政策 | 成本 | 备注 |
|---|---|---|---|---|---|
| **酷安** | 个人（实名） | 不强制（建议有） | 需要链接 | 0 元 | 内测与冷启动首选，审核快、对独立开发者友好 |
| **GitHub Releases** | 个人 | 不需要 | 不需要 | 0 元 | 开源分发，配合 GPL 合规（本仓库即主阵地） |
| **OPPO 开放平台** | 自然人个人可注册 | **需要** | 需要链接 | 0 元 | 分成约 7:3（开发者 70%） |
| **vivo 开放平台** | 自然人个人可注册 | **需要** | 需要链接 | 0 元 | 与 OPPO 材料高度重合，可一次性准备 |
| **华为 / 小米 / 应用宝** | 多要求企业主体 | 需要 | 需要 | — | 个人较难，P5 再评估 |
| **F-Droid** | 开源项目 | 不需要 | 不需要 | 0 元 | 要求**完全开源、无专有 SDK、可复现构建** |
| **Google Play** | 个人可注册 | 不需要 | 需要链接 | 一次性 $25 | 国内用户获取不便，作为海外 + 开源背书 |

> 关键结论（已核实）：OPPO 与 vivo 官方文档均确认**个人开发者可上架应用**；
> 软著自然人可申请、普通登记免费。因此本项目的"个人路径"成立，无需先注册公司。

## 二、上架材料清单（一次性备齐）

1. **签名 release 包**
   - `./gradlew assembleRelease`（先在 `local.properties` / `gradle.properties` 配好签名，
     见 [`编译与调试.md`](编译与调试.md)）；注意 `*.jks` / `*.keystore` 已在 `.gitignore` 中，不要入库。
2. **图标与截图**
   - 图标 512×512 PNG（不含他人品牌元素）；
   - 截图 ≥ 3 张，**必须含键盘实际输入画面**（展示候选旁译词），商店对输入法类目会看这个。
3. **文案**
   - 应用名（= 软著名 = 桌面名，**提交软著后不可改**）；
   - 一句话简介 + 详细介绍 + 关键词（打字、英语、背单词、离线、开源）。
4. **软著证书**（OPPO / vivo 必需）——见 [`软著材料清单与模板.md`](软著材料清单与模板.md)。
5. **隐私政策链接**——用 [`privacy-policy/index.html`](../privacy-policy/index.html) 开 GitHub Pages：
   仓库 Settings → Pages → 部署 `main` 分支的 `/privacy-policy` 目录，得到形如
   `https://xuange-hu.github.io/pickword-ime/` 的链接（目录方式时确认路径层级与页面一致）。
6. **开发者实名**：身份证 + 人脸/手持身份证（酷安、OPPO、vivo 均需）。
7. **其他常问项**：是否含广告（否）、是否收费（否）、适龄提示、无热更新声明。

## 三、节奏安排

| 阶段 | 动作 |
|---|---|

| P5 | 视体量评估华为 / 小米 / 应用宝（可能需企业主体） |

## 四、审核红线（务必自查）

- **名称一致**：软著名 = App 名 = 桌面显示名，一字不差。
- **离线声明属实**：默认不申请 `INTERNET`；若后续加联网功能，隐私政策与商店"数据安全表单"必须同步更新。
- **不得内置热更新 / 远程加载代码**：商店对输入法类目尤其敏感，避免出现动态加载 dex / 远程脚本。
- **不得使用他人品牌**：图标、名称、简介中避免出现他方商标（含"Trime / 青简 / 水杉"等图形与字样）。
- **GPL-3.0 合规**：衍生自 GPL 项目，必须提供源码（本仓库已满足）；若走 F-Droid，需保证无任何专有依赖。
- **权限最小化**：只保留输入法必需权限；导入词表用系统文件选择器，避免常驻存储权限。

## 五、开源侧（F-Droid 要点，后置）

- 需提供应用元数据（`metadata/<package>.yml`）与构建配方，要求**可复现构建**；
- 不能包含闭源/专有 SDK、不能含 Google 服务依赖；
- 由于本项目基于 GPL-3.0 的 Trime，许可证本身兼容，主要工作在去专有依赖与构建脚本。
