# 拾词输入法 · Trime 改造地图

> 基于对 `osfans/trime`（浅克隆于 `../trime-reference`）的静态分析得出。
> 结论先行：**Trime 已内置候选注释（comment）的显示机制**，译词最省力的做法是把它塞进候选的 comment 字段，显示层几乎不用改。

## 二、两条译词实现路线

### 路线 A（MVP 首选，改动最小）：Rime 方案层注入译词

- **原理**：Trime 显示层已支持 comment；让 Rime 在生成中文候选时把"英文 / 词性"作为该候选的 comment，UI 自动渲染。
- **做法**：
  1. 将 CC-CEDICT（或精简版）转成 Rime 词典 `english.dict.yaml`：词条 `中文\tEnglish / pos`（或把英文放进候选 comment 列）。
  2. 新建/改写一个 schema（如 `pickword.schema.yaml`），用 translator 把中文候选的 comment 设为英文释义；参考白霜 frost、汉英 Rime 方案的注释写法。
  3. 语言切换（英 / 日 / 西）= 切换不同翻译词典 / 方案。
  4. 关闭译词 = 在 schema 里 disable 翻译 translator，或让 comment 留空。
- **优点**：几乎不碰 Android 代码，复用现有 comment 渲染；纯离线。
- **缺点**：译词格式/样式受 Rime comment 约束，调试在 Rime 层。

### 路线 B（产品化，控制力最强）：Android 层后处理

- **原理**：在 `CandidatesPagingSource.load()` 拿到 `Array<CandidateProto>` 后，逐条查本地译词库（由 CC-CEDICT 生成的 SQLite / 内存索引），把 `comment` 改写为译词。
- **做法**：
  1. `RimeProto.kt` 的 `comment` 改为 `var`（或新建 DTO）以便后写；当前是 `val`（不可变），需调整。
  2. 在 `CandidatesPagingSource.load()` 拿到 candidates 后 `map { it.copy(comment = lookup(it.text)) }`。
  3. 译词库：CC-CEDICT 导入 Room/SQLite 或构建查询索引；语言与开关由 App 设置控制。
- **优点**：翻译逻辑、语言切换、格式、开关全在 App 内，易迭代；可与生词本共用数据源。
- **缺点**：需改数据模型 + 加 DB + 改装配点，工作量大于 A。

> **建议**：先用路线 A 跑通最小可用（一个英文词典 + schema 改写），出第一个"候选旁有英文"的包；后续再视情况迁移到路线 B 做语言切换 / 开关 / 生词本。

## 三、P2 学习闭环（全新 Android 层）

- **生词本**：Room 数据库（实体：词、释义、熟练度、下次复习时间、创建时间），与译词库可共用或独立。
- **收藏入口**：长按候选 → 在 `CandidateItemUi` / 弹窗候选增加菜单或按钮 → 写入 Room。
- **复习**：新建 `ui/main/` 下的 Activity / Fragment，实现 SM-2 间隔重复调度 + 学习趋势图。
- **词表导入**：解析四六级 / 雅思等 CSV 写入 Room。

## 四、设置与开关

- 在 `ui/main/settings/` 新增 `PickWordSettingsFragment`：语言选择（英 / 日 / 西）、译词开关、生词本入口。
- 开关写入 `trime.yaml` 或 App 私有配置；路线 A 需通知 Rime 重新加载方案（Trime 有热重载机制，参考现有方案切换代码）。

## 五、构建与上架

- **环境**：Android Studio + SDK + NDK。仓库已含 librime 预编译 so，无需自行编译引擎。
- **命令**：`gradlew assembleDebug`（本地调试）；上架用 `bundleRelease`（Play）或签名 APK（国内商店）。
- **合规**：fork 后 LICENSE 保持 GPL-3.0；不沿用"Trime / 青简 / 水杉"等他人品牌；App 名与软著名一致。

## 六、推荐起步顺序

1. 把 Trime fork 跑通 debug 包（收尾 P0）。
2. 用**路线 A**做最小译词（英文词典 + schema 改写），出"候选旁有英文"的包 → 酷安内测。
3. 视反馈决定是否迁**路线 B**，再做语言切换 / 开关 / 生词本（P2）。
